# Playhead LGPL Compliance

This repository contains the LGPL compliance materials that accompany released
App Store builds of Playhead.

Playhead uses FFmpeg under LGPL 2.1 or later. Each GitHub Release here provides
the exact FFmpeg source used by that Playhead version and the relinkable object
files needed to link a compatible modified FFmpeg build with the application.

This repository does not contain Playhead application source code.
